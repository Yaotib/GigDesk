# Workflow steps

The set-list strip on every enquiry screen: 01 Brief, 02 Lineup, 03 Price, 04 Review & export. Numbers are in Geist Mono. Completed steps show a check and stay clickable. The current step has a lime underline and `aria-current="step"`. Future steps are muted and can't be reached until earlier steps are done. On mobile it shows only the numbers plus the current label.
