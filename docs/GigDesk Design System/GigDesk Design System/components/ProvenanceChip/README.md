# Provenance chip

A provenance chip states where a value came from: AI-read, Check (uncertain), Missing, Confirmed, a rule ID (calculated), Manual, or SAMPLE DATA. Place one per field or line item, right-aligned in the row. Status is never conveyed by colour alone: every chip has a word and, except rule IDs, a Lucide icon. A rule chip such as `R-04` expands to its rule trace on click or tap.
