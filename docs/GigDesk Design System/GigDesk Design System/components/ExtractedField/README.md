# Extracted field

AI-read values carry a dotted underline until a person confirms or edits them. Tapping the value edits it inline, and saving turns the chip into Confirmed. Missing fields show 'Not in the brief' in `ink-subtle` and feed the follow-up draft. Group rows under Client, Event and Production headings. On mobile the label sits above the value.
