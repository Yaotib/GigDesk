# App shell

A dark sidebar (`sidebar`, 232px) on a `canvas` page. Sections are Main (Overview, Enquiries, Upcoming events), Management (Quotes & invoices, Production riders) and Configuration (Business settings). The active item gets a `sidebar-raised` row and a 3px lime marker on the left edge. Counts are in mono, `sidebar-muted`. The page header has a 24px title on the left and one primary action on the right. Below 768px the sidebar becomes a dark top bar with a menu sheet, and the primary action moves to a bottom bar.
