# Quote summary

The itemised financial table. Every amount is in Geist Mono, right-aligned, with tabular numerals. Each line carries a rule chip and a one-line trace in mono ("3 h × GH₵200.00 × 4 musicians"), or a Manual chip plus the reason the team gave. A hairline in `ink` separates the total, which is shown in `figure-total`. Deposit and balance sit side by side directly underneath, each with its due rule. Tax lines show their configured name and are labelled TBC until confirmed. On mobile, Qty and Rate collapse into the trace line.
